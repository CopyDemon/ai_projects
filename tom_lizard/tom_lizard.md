# Tom Lizard

我的第一个 AI agent，完全在本地启动和运行。吉祥物是 `tom_icon.png` 里那只张嘴的绿蜥蜴。

这个项目首先是学习项目，边学边做，慢慢来。

## 愿景

长期目标很大：一步一步把 Tom 做成一个越来越通用、越来越聪明的 agent，往 AGI 的方向走。

短期目标实际一点：每个阶段结束时，Tom 都要是一个真能用的应用，不是一堆练习代码。

## 文件夹结构

- `tom_lizard.md` 这个文件，记项目的愿景、路线图、技术方案和进度
- `environment.md` 环境记录：装了哪些软件、模型、包，为什么装，怎么启动，怎么重建。详情见下面导入的内容
- `environment.yml` conda 环境配置，用来一条命令重建环境
- `course/` 课程，一课一个小程序，学一个概念。详情见下面导入的 course.md
- `research/` 查到的资料，留着以后深入时用。这些文件**不导入** CLAUDE.md，免得每次开会话都占地方，要用时再打开看
  - `model_customization.md` 怎么改造现成的模型：提示词、Modelfile、微调 LoRA
- `app/` Tom 的正式应用代码。现在有网页界面：`agent.py` 是大脑，`main.py` 是后端，`static/index.html` 是聊天网页
- `tom_icon.png` 吉祥物图标

## 路线图

这是草稿，边学边改。

1. **基础**：agent 循环，工具调用。已完成第一课
2. **能对话**：有网页界面，能一直聊下去，记得前面说过的话。已完成网页界面和多轮对话，还差回答一个字一个字地流出来
3. **能动手**：给 Tom 真正有用的工具，比如读写文件、跑命令、查资料
4. **能记事**：长期记忆，关掉再打开还记得你是谁、之前做过什么
5. **能规划**：把大任务拆成小步骤，一步步做，做完自己检查
6. **有界面**：做成桌面或网页应用，不用开终端也能用
7. **更强更通用**：多个 agent 分工合作，从经验里学习，换更强的模型。需要时再考虑微调，资料见 `research/model_customization.md`

## 要求

1. 必须在本地启动、本地运行，模型用 Ollama 跑，不调用云端 API
2. 模型要支持 tool calling

## 技术方案

目前用的：

- 模型：`qwen3:8b`，5.2GB，支持 tools 和 thinking。官方 tool calling 文档的例子就用它。以后需要更强的可以试 `qwen3.6:27b`，19GB
- 语言：Python 3.12，conda 环境 `tom_lizard`
- 库：官方 `ollama` Python 库 0.6.3
- 网页：后端 FastAPI 0.142.2，用 uvicorn 0.54.0 跑。前端是一个手写的 HTML 文件，不用任何前端框架
- 端口：Tom 网页 8000，Ollama 11434。都只有本机能访问
- agent 循环：先自己手写，弄懂原理，以后再考虑框架

## 已知问题

1. 模型会自己心算然后把错的数字传给工具，2026-10-02 网页测试时真实出现过
2. 偶尔用英文回答中文问题
3. 回答要等全部生成完才显示
4. 没有指定上下文长度，Ollama 0.40.0 默认用 32768，每次加载占 10GB 左右。聊很长以后超出上下文会怎样还没测过
